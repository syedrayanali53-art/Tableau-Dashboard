## How to view the project

1. Download the workbook file from this repository.
2. Open it in Tableau Desktop or Tableau Public.
3. Explore the worksheets, dashboard elements, and filters.
4. If a source connection is missing, open the workbook in Tableau and review the structure, visuals, and design logic.

> Note: Some Tableau workbooks reference local data sources. If the underlying dataset is unavailable, the workbook itself still provides a useful view of the design and analytical structure.

## Featured project

### Tableau Project 1

Open the workbook here: [Tableau Project 1.twb](./Tableau%20Project%201.twb)

This project focuses on exploring and presenting data through a clean Tableau dashboard. It is intended to demonstrate data exploration, chart selection, and dashboard communication in a way that is easy for a viewer to understand.

### What to review in the workbook

- worksheet structure and dashboard layout
- filters, actions, and interactions
- chart type choices and visual hierarchy
- storytelling flow across the dashboard
- overall readability and design decisions

## How to view the project

1. Download the workbook file from this repository.
2. Open the file in Tableau Desktop or Tableau Public.
3. Review the dashboard, charts, and filters.
4. Refer to the project notes for context and guidance.

> Note: Some Tableau workbooks reference local data sources. If the source data is not available, the workbook can still be reviewed for layout, composition, and design logic.
